02

什麼時候學什麼

下面六站不用照順序全部學完才能開始做東西。每一站都寫了什麼時候該學它，沒遇到那個情況就先跳過。時間是抓每週投入五到十小時估的，實際會因人差很多。

這些現在不用學

  • 做同一件事的第二個。學了 React 就不用再學 Vue，用了 PostgreSQL 就不用再學 MySQL。只要網路上有人在寫文章比較兩個東西，那就代表它們是對手，挑一個就好。
  • 名字裡有 plugin、loader、-config 的。這些是別人工具的擴充功能，本身不是拿來「學」的，用到再查就好。
  • Docker、Kubernetes。在你需要「同一份程式要部署到很多台機器」之前都用不到。個人專案交給 Vercel 這類平台就夠了。
  • GraphQL、微服務。這兩個是大團隊拿來解決大團隊問題的做法。小專案照最普通的方式寫，反而比較好維護。
  • C++、Rust。除非你要做遊戲引擎、作業系統或很吃效能的工具。看到名字知道它們負責什麼就夠了。

06

洋蔥圖：誰在誰上面

上下層關係畫出來，就是一層疊一層，像洋蔥。
最外面那層是你寫的，往裡面每一層都是別人已經寫好的。你只碰最外面，但裡面每一層都在跑。
左邊是四條真實的鏈。點任何一層，右邊卡片會說明它是什麼。

← 點洋蔥圖上任何一層，這張卡片會說明它是什麼、它底下是誰、同一層還有哪些選擇。

下次看到不懂的名詞，先問它是六種關係裡的哪一種，再問它在哪一層。
這兩題問完，大部分的名詞就不會那麼陌生了。剩下的通常要真的動手做過才會懂。
