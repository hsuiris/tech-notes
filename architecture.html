02

依需求安排學習順序

以下以建立網頁服務為主，列出六個學習階段。可依目前需求選擇，不必全部完成才開始實作。時間是每週投入五至十小時的粗略練習安排，並非熟練程度的保證。

可以依專案需要再深入的主題

  • 同類工具：先熟悉一個能滿足需求的選擇，再理解其他工具的差異。工具被放在一起比較，不代表功能完全可互換。
  • 外掛與設定：先認識主要工具，再依使用情境查閱擴充功能與設定。名稱只能提供線索，實際用途仍需查閱文件。
  • Docker 與 Kubernetes：前者有助於一致的執行環境，後者管理容器化工作負載。即使只有一台機器，也可能需要 Docker；是否導入應依部署需求決定。
  • GraphQL 與微服務：分別涉及資料查詢介面與服務拆分。先理解需求與維運代價，再判斷是否採用，不能僅以團隊規模決定。
  • C++ 與 Rust：常見於系統、遊戲與效能敏感的程式。若目前目標是一般網頁，可先理解其用途，遇到需求再深入。
